# Historical material

- `legacy-checkout-2026-11-08/`: files absent from or byte-different from the current checkout. Older reports and code are deliberately retained here without replacing current versions.
- `workspace-handoffs-2026-11-08/`: browsable handoffs, audit scripts, manifests, and screenshots previously stored outside the repository.

Complete snapshots, including larger files, are in the [consolidation release](https://github.com/Mohnclizzy/FRI-BCI-ML-RL-Decoder-Personal/releases/tag/local-consolidation-2026-11-08).
