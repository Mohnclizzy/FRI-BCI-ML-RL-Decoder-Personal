# Near-table anti-push PPO diagnostic — frozen protocol

The progress policy repeatedly pushed the table cube sideways with mostly right-finger contact. This diagnostic adds one bounded reward term to the existing near-table progress task: -2 times tanh(horizontal cube displacement from its fixed reset / 0.05 m). It applies throughout the episode, including lift; this may discourage useful movement and can be exploited by inaction. All other task settings and physical success criteria remain unchanged. The fixed reset is table-supported near the cube, not the farther table approach; results cannot establish ready-pose pickup.
