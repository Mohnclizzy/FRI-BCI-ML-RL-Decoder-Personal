# Continuous native BC-RNN HOLD/resume protocol (frozen before matched batch)

Checkpoint: official Lift PH low-dimensional BC-RNN, SHA256 `3ee222cab41f78ba27afca7ef6f70f9f21bd3cc0a37bd79c0b2351dbede51605`; native 20 Hz control, 500 Hz physics, 400 actions and 20-second deadline. The prior acquisition-only HOLD result is diagnostic and excluded from this batch. No checkpoint, simulator, or task reward changes.

Matched seeds 0, 1, 2; each has an uninterrupted policy, an always-HOLD control, and six pauses: start steps 15 (approach), 35 (closure), and 70 (carrying), with 10-step (0.5 s) and 60-step (3 s) durations. Pause steps denote the actions replaced by HOLD. Those phase names are approximate windows from the earlier native traces; telemetry determines the actual observed phase. The first successful 400-step always-HOLD probe in a separate run directory is not part of the scored batch.

At each HOLD entry, capture measured end-effector position/orientation as an absolute OSC_POSE goal, the Panda gripper's current actuator command, and cube position. Every HOLD action is seven zeros. The pose controller is called every physics substep with the captured absolute goal; Panda's `format_action(0)` maintains its prior actuator command. No BC-RNN call occurs in HOLD; its hidden state and call counter freeze. On resume the next call consumes the latest simulator observation. The model's native 10-call recurrent horizon resets by call count, not elapsed simulator time. There is no separate input history queue. Do not reset the policy on resume. Successful completion is decided at the fixed horizon and is terminal; no later command can change it.

Frozen scoring: acquisition is bilateral fingerpad/cube contact and cube rise >=0.08 m above the episode's initial center height; sustained contact is >=10 consecutive sampled control states; terminal retention requires both contact and rise at the terminal state and no sampled contact or height loss after acquisition. A drop is any such post-acquisition loss. HOLD goal position and orientation matrix error must be <=1e-9, gripper actuator-command error <=1e-9, and policy/RNN call violations zero. Descriptive physical drift limits are end-effector 0.035 m and cube 0.025 m relative to each HOLD-entry state; score them separately from exact goal invariance. Contact telemetry is sampled at 20 Hz, so substep contact breaks remain unobserved. Native reward and exit status are never success criteria.

Decision replay, if controls pass, uses the existing causal `DecisionReplay` JSONL contract (same source/episode, ordered estimate/availability/issue times, 1 s stale watchdog), ported to Python 3.8 for this historical runtime. It will be explicitly exploratory because the public EEG recordings and gates have already been inspected.
